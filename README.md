# Cóctelix — versión con imágenes originales del PDF

Esta versión conserva las 246 recetas de Cóctelix y usa las imágenes de cócteles **extraídas directamente del PDF EVERYDAYCOCKTAIL-E-BOOK.pdf**.

- 246 recetas
- 246 imágenes individuales
- Imagen en cada tarjeta y en el detalle de la receta
- Favoritos y búsqueda
- Compatible con GitHub Pages

Para actualizar GitHub Pages: reemplaza los archivos de tu repositorio con el contenido de esta carpeta y conserva la carpeta `images/`.
